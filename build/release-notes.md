**Nouveau dossier du jeu : `.Nerysia`**
- Le jeu s'installe maintenant dans le dossier `.Nerysia` (avant : `.helioslauncher`, le nom du launcher d'origine).
- Au premier clic sur **Jouer**, le jeu et Java sont retéléchargés **une seule fois** dans ce nouveau dossier.
- L'ancien dossier `.helioslauncher` n'est plus utilisé : tu peux le supprimer pour libérer de la place (garde avant tes captures d'écran ou mondes solo si tu en as).
- Si tu avais choisi un autre dossier dans les paramètres, rien ne change.

**Autres changements**
- Les notes de version affichées dans les paramètres sont maintenant celles de Nerysia.
- Sur Mac, Minecraft s'appelle « Nerysia » dans le Dock.
